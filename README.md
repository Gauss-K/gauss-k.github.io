# Gauss-K — multipage academic website

This is a dependency-free static website for GitHub Pages.

## Pages

- `index.html` — concise homepage and site navigation
- `research.html` — Complex Relativity, P1/P2, open questions
- `publications.html` — DOI, Zenodo CRSF, GitHub and alphaXiv links
- `writing.html` — The Dreamless Machine and The Nameless Box
- `about.html` — about, research approach and contact
- `styles.css` — shared responsive styles
- `favicon.svg` — site icon

## Deploy

1. Extract this ZIP.
2. Open the `Gauss-K/gauss-k.github.io` repository on GitHub.
3. Upload all **seven website files** to the repository root (not the ZIP file itself). Existing `index.html` will be replaced. You can also upload this README.
4. Commit the changes to the `main` branch. GitHub Pages will deploy automatically if Pages is configured for `main` and `/ (root)`.
5. Visit `https://gauss-k.github.io/`.

Every internal navigation link points to a separate HTML file. Keep the page files and `styles.css` together at the repository root.

The content intentionally avoids using the word previously requested to be removed and retains the agreed wording, headings, external links and restrained scientific claims.
